# Security reporting

This repository contains public project documentation. It does not contain the reporting implementation, credentials, private report, or a public reporting service.

For a suspected exposure in this showcase, contact **KSAGlory** privately through the [KSA community](https://discord.gg/ksahub). Start with a brief description without secrets; the maintainer can arrange a suitable way to share details. Do not post the report in a public channel or GitHub Issue.

Never publish provider tokens, OAuth client secrets, credential identifiers, account details, private report links, workflow exports, recovery archives, or unredacted execution logs. There is no public deployment support matrix or response-time guarantee.
