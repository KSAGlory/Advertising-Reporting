# Feedback and support

Advertising & Reporting is a private personal automation. This repository offers project information, not an installable workflow or a supported public deployment package.

Use [GitHub Issues](https://github.com/KSAGlory/Advertising-Reporting/issues) for documentation corrections, project questions, or reporting suggestions. State which documented behavior you are discussing and distinguish a proposed improvement from verified functionality.

Keep account identifiers, contact data, provider credentials, private destination links, workflow exports, backups, and runtime logs out of public posts. Do not upload screenshots of private reports without removing sensitive information.

Security concerns belong in the private route described in [SECURITY.md](SECURITY.md). Installation support, source contributions, and commercial onboarding are not offered through this showcase.

Community: [discord.gg/ksahub](https://discord.gg/ksahub).
